# 타회사 실적 회사별 카드 개편

## 구현 내용
- 타회사 실적 화면만 기존 사업 전체 목록 대신 전직장 회사명별 카드 목록으로 표시합니다.
- 상단에 회사명·기술자명 검색창과 `회사 등록`, 엑셀 양식·가져오기 기능을 배치합니다.
- 각 카드에 회사명, 총 실적 건수, 전체 사업에서 중복 제거한 참여 기술자 태그, `실적 추가`, `실적 목록 보기`를 표시합니다.
- 카드 또는 목록 버튼을 누르면 해당 회사의 사업만 보여주는 상세 창을 열고, 기존 수정·복사·삭제·파일 다운로드·선택 삭제 기능을 유지합니다.
- 상세 창과 카드의 `실적 추가`는 기존 등록 양식을 해당 회사명으로 미리 채워 바로 열도록 연결합니다.
- 회사 등록은 회사명을 먼저 입력한 뒤 해당 회사의 첫 사업 등록으로 이어지게 하여, 빈 회사 카드가 생기지 않도록 처리합니다.
- 회사명이 비어 있는 기존 실적은 `회사명 미등록` 그룹으로 묶어 누락 없이 보여줍니다.
- 기존 자회사 실적 데이터베이스 화면은 변경하지 않습니다.

## 확인
- 모바일과 데스크톱에서 카드, 검색, 상세 창, 추가 버튼 흐름을 확인합니다.
- 현재 데이터의 회사별 건수와 참여 기술자 중복 제거 결과가 정확한지 확인합니다.
- 빌드 및 화면 오류를 점검합니다.
