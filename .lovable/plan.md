# PQ 기술자 실적 출력 양식 개편

## 구현 범위
- 기존 `PQ 기술자 실적관리`의 엑셀 내보내기와 실적 PDF 출력 진입점을 하나의 **양식 설정 창**으로 연결합니다.
- 왼쪽에서 출력 항목을 포함/제외하고 드래그해 순서를 바꾸며, 오른쪽 A4 미리보기에 즉시 반영합니다.
- 기본 항목은 용역명, 준공금액(전체/지분), 평가종류, 용역기간, 참여기간, 환산건수, 담당업무, 참여당시(소속/직위), 발주처, 비고 등 현재 저장된 실적 자료에서 구성합니다.
- 자주 쓰는 구성은 이름을 붙여 기기별 양식 템플릿으로 저장·불러오기·삭제할 수 있게 합니다.

## 출력 결과
- **엑셀:** 제목, 2단 병합 헤더, 테두리, 헤더 배경, 정렬, 숫자 형식, 열 너비를 적용한 제출용 표로 생성합니다.
- **인쇄 설정:** A4 방향을 열 수에 따라 가로/세로로 정하고, 모든 열을 한 페이지 너비에 맞추도록 설정합니다.
- **PDF:** 동일한 열 구성과 2단 헤더를 사용해 A4 표 형태로 생성하며, 긴 내용은 줄바꿈하고 여러 페이지에서는 헤더를 반복합니다.
- 현재 제공되는 원본 증명서/참여자명단 병합 기능은 별도 기능으로 유지합니다.

## 사용 흐름
1. 엑셀 또는 PDF 출력 버튼 선택
2. 출력할 실적과 항목 구성 확인
3. 드래그로 순서 변경, 항목 포함/제외, A4 방향 선택
4. 필요하면 양식 템플릿 저장
5. 미리보기와 같은 구성으로 엑셀 또는 PDF 다운로드

## 기술 세부사항
- 기존 실적 필터와 선택 상태를 그대로 사용해 현재 화면에서 선택된 자료만 출력합니다.
- 출력 열 정의와 2단 헤더 구조를 공용 모듈로 분리해 엑셀/PDF 결과가 일치하도록 합니다.
- 한국어 PDF 글꼴은 브라우저에서 사용할 수 있는 한글 글꼴을 포함해 글자가 깨지지 않도록 처리합니다.
- 드래그 앤 드롭은 마우스와 터치 입력을 모두 지원하고, 키보드용 위/아래 이동 버튼도 제공합니다.
- 템플릿은 사용자별 브라우저 저장소에 보관합니다.

## 확인
- 타입 검사와 기존 테스트를 실행합니다.
- 데스크톱과 모바일에서 설정 창, 드래그/순서 변경, A4 미리보기, 엑셀/PDF 다운로드를 실제로 확인합니다.
